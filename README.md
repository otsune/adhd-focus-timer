# ADHD Focus Timer

**▶️ [今すぐWebブラウザで使う](https://tagkaz.github.io/adhd-focus-timer/)**（推奨）

ADHD特化型・強制着手タイマーの「集中継続特化・カウントアップ版」です。

本プロジェクトは、旧版にあたるポモドーロ用タイマー（究極ポモドーロ）から派生した新規バージョンです。
前作のように「時間が来たら強制的にシステムが休憩時間を挟む」といったポモドーロ手法を廃止し、**「自発的な集中継続の支援」**と**「累積集中時間の可視化」**を最大の目的として再設計されています。

## 目指していること

- **着手のハードルを極限まで下げる:** 「ルーレット開始」等で迷いを断ち切ってすぐに行動に移せます。
- **集中を妨げない:** システム主導の強制終了や休憩遷移を行わず、ユーザーの集中が続く限りタイマーはカウントアップし続けます。
- **「ここまで来た」を実感させる:** 長い集中区間の中で、15分おきに発生する節目通知（フラッシュとチャイム）により、時間の経過と達成感を可視化します。
- **中断後の再着火を支援する:** 離席・食事後は「復帰モード付き初期画面」へ遷移し、元タスクの大きな再開ボタンが最優先で表示されます。「今日はもう終了」に落ちるのを防ぐ設計です。
- **比較による自己嫌悪を生まない:** 集計画面はあくまで「報酬画面」として設計されており、前日比や長期比較など自己嫌悪を誘発しやすい要素を持ちません。

## 主な特徴

* **カウントアップタイマー:** 00:00から開始し、ユーザーが「離席」「食事」または「終了」を選ぶまで無限にカウントアップします。
* **15分ごとの節目通知:**
  * 15分, 45分, 75分...（奇数回）：画面が赤く3回フラッシュします。
  * 30分, 60分, 90分...（偶数回）：音声と「〇〇分経過」というトーストメッセージで節目を通知します。
* **作業中ボタン（離席 / 食事 / 終了）:** 集中画面には3つのアクションがあります。
  * **「離席」「食事」**: それまでの集中区間を記録し、復帰モード付き初期画面へ遷移します。
  * **「■ 終了」**: 集中区間を記録し、集計画面へ遷移します。
* **復帰モード付き初期画面:** 離席・食事の後は、専用の中断画面を経由せず初期画面へ直接戻ります。最上段に直前タスクの大きな再開ボタンが表示され、その下に他タスク一覧・ランダムボタン・終了リンクが続きます。視線誘導の優先順位を「再開 > 別タスク > ランダム > 終了」に固定することで、中断後の再着火を促します。
* **再開フラッシュ（報酬演出）:** 復帰モードから何かのタスクを開始した瞬間に赤フラッシュが入ります。「戻れた」こと自体を報酬として強化します。
* **集計画面（報酬画面）:** 今日の初回着手時刻・午前中着手判定・累積集中時間・最長連続時間・着手回数・ベストセッションを表示します。前日比や比較表示は含みません。
* **午前4時区切りの日次集計:** 徹夜などで深夜0時を跨いだ場合でも、午前4時を1日の境界として自動的にセッションを分割・集計します。
* **スマホ完全対応のレスポンシブ設計:** PCだけでなく、スマートフォン等のモバイル端末から開いてもレイアウトが崩れず、快適に操作できるよう最適化されています。
* **環境非依存のデータ保存:** アプリはサーバー不要で `public_html/index.html` 単体で動作します。データはブラウザの `localStorage` に保存されます（キープレフィックス: `_v2`）。

## 使い方

### 1. 起動
本プロジェクト内にある `public_html/index.html` をお使いのウェブブラウザ（Google Chrome, Safari, Edge など）で開くだけで起動します。ローカルサーバー等は不要です。

### 2. タスクを開始する
- メイン画面の入力欄にこれから取り掛かるタスク名を入力します。
- **「開始 ▶」** ボタンを押すと集中画面へ遷移し、カウントアップが始まります。
- どのタスクから始めるか迷った場合は、**「決められない時（開始）」** ボタン（ルーレット）を押すことでランダムにタスクを決定し、強制的にスタートさせることができます。

### 3. 中断と終了の使い分け
集中画面には3つのボタンがあります。

* **「離席」「食事」**: ちょっとした離席や食事の際に使用します。それまでの集中区間が記録されたあと、**復帰モード付き初期画面**へ遷移します。中断中の時間は集中時間に加算されません。現時点では両者の内部処理は同じで、違いは中断理由のラベルです。
* **「■ 終了」**: 本日の作業を終える際に使用します。最終的な集中区間が記録され、集計画面が表示されます。

### 4. 復帰モードから再開する
「離席」「食事」を押すと復帰モード付き初期画面が表示されます。

1. **直前タスクの再開ボタン（最大サイズ）** ── 同じタスクへ戻る場合はここを押すだけ
2. 他の登録タスクボタン（固定順）
3. ランダムボタン ── どれでもいいからとにかく再開したい場合
4. 終了リンク（極小）── 本当に今日は終わりにしたい場合のみ

> 同じタスクに戻れなくても、別タスクを開始できれば成功です。

### 5. 本日の成果（集計）を確認する
タスクを終了した直後、またはメイン画面の **「📊 今日の成果」** ボタンから集計画面を開くことができます。
ここにはその日（午前4時区切り）の初回着手時刻・午前中着手判定・累積集中時間・最長連続時間・着手回数などが表示されます。

## データのエクスポート（分析用）

保存された作業記録をスプレッドシートやPython等で分析したい場合、**⚙️ 設定** 画面内の **「📥 JSON エクスポート」「📥 CSV エクスポート」** ボタンからダウンロードできます。

* **JSON**: 完全なログや設定を含むバックアップ/再集計用のデータ形式。
* **CSV**: 1行1集中区間（タスク名、開始時刻、終了時刻、継続秒数）のExcelやスプレッドシートで扱いやすい形式（BOM付きUTF-8）。

*※ データはすべてユーザーのブラウザ（`localStorage`）内にのみ保存され、外部サーバーへ自動送信されることはありません。*

---

## バージョンについて

このバージョン（v2）は旧版（v1）と **localStorageのキーが完全に分離**されています（`tasks_v2`, `logs_v2`, `settings_v2`, `activeState_v2`）。旧版のデータ（タスク登録・ログ・設定）は自動移行されません。旧版と同じブラウザで使用している場合でも、互いのデータに影響を与えません。
