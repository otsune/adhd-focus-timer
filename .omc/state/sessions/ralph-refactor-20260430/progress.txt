## Bug Found and Fixed by Architect Review

**Bug**: src/app.js の initAudio インポート漏れ
- initAudio() が btn-roulette のイベントハンドラで呼ばれているが、app.js に audio.js のインポートがなかった
- フラットビルドではグローバルスコープで解決されるため hidden だったが、dev mode (ESM) では ReferenceError
- **Fix**: `import { initAudio } from './audio.js';` を app.js に追加

## Patterns Learned

1. フラットビルドシステムでは同名の const/function 宣言が SyntaxError になる → app-utils.js で共通化
2. 複数モジュールにまたがるコールバック注入は initApp() で一括初期化 → 明示的な依存関係
3. モジュールスコープ変数のリセット関数をテスト用に export する (clearUndoState など)
4. アーキテクト審査で dev path と flat build path の差異バグを検出 → 開発モードテストの重要性
